# 🎓 Student Exam Performance Indicator

An end-to-end Machine Learning web application that predicts a student's **Math score** based on demographic and academic features using a trained ML model served via Flask.

🔗 **GitHub Repository:** [https://github.com/johntakal/Student-Exam-Performance-Indicator](https://github.com/johntakal/Student-Exam-Performance-Indicator)

---

## 📌 Problem Statement

Given information about a student (gender, race/ethnicity, parental education level, lunch type, test preparation course, reading score, and writing score), predict their **Math exam score**.

## ⚙️ Setup & Installation

### Prerequisites
- Python 3.8+
- pip

### 1. Clone the repository

```bash
git clone https://github.com/johntakal/Student-Exam-Performance-Indicator.git
cd Student-Exam-Performance-Indicator
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 🚀 How to Run

### Run the Flask Web App

```bash
python app.py
```

Then open your browser and go to:

```
http://127.0.0.1:5000/predictdata
```

### Web App Routes

| Route | Method | Description |
|---|---|---|
| `/` | GET | Landing / home page |
| `/predictdata` | GET | Show the prediction form |
| `/predictdata` | POST | Submit form → get predicted Math score |

---

## 🌐 Using the Web App

1. Navigate to **http://127.0.0.1:5000/predictdata**
2. Fill in the student details:
   - **Gender** — Male / Female
   - **Race/Ethnicity** — Group A–E
   - **Parental Level of Education** — Some High School → Master's Degree
   - **Lunch Type** — Standard / Free or Reduced
   - **Test Preparation Course** — None / Completed
   - **Writing Score** — 0 to 100
   - **Reading Score** — 0 to 100
3. Click **🎯 Predict Math Score**
4. The predicted score appears with a **progress bar** and **letter grade** (A+/A/B/C/D/F)

---

## 📊 Results Display

After prediction, the app shows:
- 🔢 **Predicted Math Score** (out of 100)
- 📊 **Animated progress bar** scaled to the score

  - 🟢 A+ (90–100) · A (80–89)
  - 🔵 B (70–79)
  - 🟡 C (60–69)
  - 🟠 D (50–59)
  - 🔴 F (< 50)

## 🗃️ Dataset

The dataset (`stud.csv`) contains **1000 student records** with the following features:

| Feature | Type | Description |
|---|---|---|
| `gender` | Categorical | Student gender |
| `race_ethnicity` | Categorical | Ethnic group (A–E) |
| `parental_level_of_education` | Categorical | Parent's highest education |
| `lunch` | Categorical | Lunch type (standard / free-reduced) |
| `test_preparation_course` | Categorical | Completed or none |
| `reading_score` | Numerical | Reading exam score (0–100) |
| `writing_score` | Numerical | Writing exam score (0–100) |
| `math_score` | Numerical | **Target variable** — Math exam score |
